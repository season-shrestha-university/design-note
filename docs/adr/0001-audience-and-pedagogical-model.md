# ADR-0001: Audience and pedagogical model

## Status

Accepted

## Context

Design Note is a university major project. It must differentiate from long-form design blogs that overwhelm beginners with dense, expert-level content.

## Decision

Design Note adopts a **breadth-first, progressive-disclosure content model** targeting **UX-curious beginners with no prior knowledge**.

Learners get a wide map of UX topics first. Depth lives in external Further Reading links, not on Design Note itself.

## Consequences

- Articles stay short and scannable; comprehensive detail is offloaded externally
- The site is a **map**, not a **course** — learners browse broadly, then choose where to go deeper
- Content that reads like a deep expert essay must still obey the beginner-friendly editorial contract
- Features (search, navigation, homepage ordering) should serve discovery across categories, not expert retrieval
